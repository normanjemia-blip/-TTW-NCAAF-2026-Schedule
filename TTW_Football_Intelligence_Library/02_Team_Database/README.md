# 02 — Team Database

**Phase 3 deliverable.** One standardised intelligence file for each of the 138 FBS teams in the guide. Every file carries the same 29 headings in the same order; a heading the guide does not address reads exactly `Not addressed in guide.` rather than being dropped.


Each file draws on the **whole guide**, not only that team's two-page preview — conference previews, best bets, win totals, the coaching carousel, staff predictions, Stability Scores and every other team's pages.


## Standard schema


1. Program Snapshot · 2. Conference · 3. VSiN Team Rank / Conference Rank · 4. Steve Makinen Power Rating · 5. Home-Field Advantage Reference · 6. Head Coach · 7. Coordinator Notes · 8. Coaching Continuity / Changes · 9. Quarterback Situation · 10. Returning Production · 11. Transfer Portal · 12. Recruiting / Roster Notes · 13. Offensive Identity · 14. Defensive Identity · 15. Key Strengths · 16. Key Weaknesses · 17. Schedule Overview · 18. Difficult Stretches / Trap Spots · 19. Win Total Discussion · 20. Futures / Conference / Playoff Discussion · 21. Betting Notes / Best Bets · 22. Historical / Situational Trends · 23. Important Statistics · 24. Bull Case · 25. Bear Case · 26. Open Questions / Risks · 27. Source Conflicts · 28. Relevant Page References · 29. Cross-Links
