## 3. TeamRankings load detail

- Source: `https://www.teamrankings.com/college-football/ranking/predictive-by-other`
  (server-rendered HTML `<table>`, not an API — but a structured table, not
  prose). Retrieved: 2026-07-19.
- Raw HTML archived in
  `raw_sources/teamrankings_predictive_2026preseason_20260719.html`.
- Team matching: TeamRankings uses its own, non-ESPN abbreviation
  convention (e.g. "N Illinois", "S Florida", "J Madison", "Mississippi"
  for Ole Miss). Every one of the 138 TeamRankings names was manually
  checked against the canonical `TEAM MAP` list and mapped to its
  abbreviation — see `tr_teams_dump.txt` (raw parsed rank/name/rating) and
  the `TR_TO_ABBREV` table in the load script. Result: **138/138 matched,
  0 unmatched, 0 canonical abbreviations left without a match.**
  Disambiguation-prone cases were individually verified, not
  pattern-guessed:
  - Directional prefixes: "N Texas" -> North Texas (UNT) vs. "N Illinois"
    -> Northern Illinois (NIU); "S Florida" -> South Florida (USF) vs.
    "S Alabama" -> South Alabama (USA); "E Carolina"/"E Michigan"/
    "W Michigan"/"C Michigan" -> East/Eastern/Western/Central, checked
    individually since the prefix expands inconsistently.
  - "Mississippi" -> Ole Miss (MISS) vs. "Mississippi St" -> Mississippi
    State (MSST) — confirmed both present as distinct rows.
  - "J Madison" -> James Madison (JMU); "UL Monroe" -> ULM; "Sam Houston"
    and "UMass" already matched their canonical names directly.
- Matched data: `tr_matched.json`.
- Loaded into `PRESEASON!Q:S` (raw / date / cite) for rows 6:143.

## 5. Formula behavior verified with only 2 of 5 sources loaded

The `PRESEASON` tab's existing (pre-Phase-4, unmodified) formula columns
implement the approved "missing is not zero — renormalize over available
sources" rule (`Y`: available weight, `Z`: final prior, `AA`: source
count, `AB`: single-source flag). With only FPI (weight 0.25) and
TeamRankings (weight 0.15) populated, every one of the 138 rows now
computes:
- Available weight `Y` = 0.40 (0.25 + 0.15) for all 138 rows (constant,
  since FPI and TR have no per-team gaps).
- Source count `AA` = 2 for all 138 rows; single-source flag `AB` blank
  for all 138 (correctly not flagged, since 2 sources qualifies as
  multi-source).
- Final prior `Z` recomputed as the weight-renormalized blend of just
  FPI-norm and TR-norm.
- Sanity check on the resulting blended ranking: top 5 = Ohio State,
  Texas, Notre Dame, Oregon, Georgia; bottom 5 = UMass, Sam Houston, ULM,
  Kent State, Ball State — consistent with both sources' individual
  preseason rankings.

This was verified by independently reproducing the exact formula text in
Python against the loaded values (not by guessing) — see the diff/parity
check described in Section 6.

## 8. SETTINGS!B22 / B23 (totals subsystem) — left blank, documented

`SETTINGS!B22` (League average total) and `B23` (Total EPA scale) were
marked "BLANK until Phase 4" in the original build. They were **not**
populated in Phase 4, and the reason is documented in the CHANGELOG:
their only consumer is `ENGINE` column Y (projected game total), which
also requires per-team EPA values flowing from `IMPORT STATS` via `CALC`
E/F → T:W — and that EPA stats pipeline is (a) CFBD/cfbfastR-sourced,
blocked without an API key, and (b) in-season data that does not exist
yet in July. `ENGINE!Y` correctly shows blank/NOT AVAILABLE while
B22/B23 are blank, so no placeholder value was invented. These two
constants should be populated when the stats pipeline unblocks.
