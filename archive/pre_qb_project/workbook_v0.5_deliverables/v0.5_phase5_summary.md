## 1. FCS opponent-rating framework — built and loaded

All **100** distinct FCS programs on the approved 2026 schedule (from the
888-row verified schedule) received an individually **verified numeric
rating** — not a bucket guess. `FCS TIERS!J6:M105`.

**Why not an external named source (e.g. Massey Ratings):** attempted
first; `masseyratings.com` returns HTTP 403 (Cloudflare bot-challenge) to
this session. No other external FCS rating source is named in the
approved architecture.

**Methodology used instead** (new construction this phase, documented in
full in `DICTIONARY!B21` and `srs_rating.py`): an iterative
opponent-adjusted-margin solve (SRS-style fixed point) over the complete
2025 FBS+FCS completed-game graph — 315 teams, 1,686 completed games,
fetched fresh from ESPN's structured scoreboard API
(`site.api.espn.com`, groups 80+81, all weeks/seasontypes; raw JSON for
every one of the 42 fetched week/group/seasontype combinations archived
in `raw_sources/`). Per-game performance margin = score differential,
home-field-adjusted (±2.5, 0 if neutral), capped ±28 (same cap named for
the approved FBS TTW-prior technique). Solved to a true fixed point
(500-iteration cap, converged to <1e-10 in 205 iterations) and
mean-centered so the FBS subset averages exactly 0. A team receives a
rating only with ≥6 completed 2025 games — **none of the 100 fell short**
(minimum was 12).

A **4-tier evidence-based fallback** (`FCS TIERS!A6:D9`) was also built —
quartiles of every rated (≥6-game) non-FBS team in the same 2025 graph —
clearly labeled as unused-by-the-current-100 reserve infrastructure for
any future opponent without an individual rating. The 5th tier,
`Transitional/uncertain`, is explicitly left **blank** (no value
invented) for teams that would fall below the 6-game floor.

Both NDSU and Sacramento State are confirmed **absent** from the FCS
override table (they are FBS-reclassifying, not FCS, per
`FCS TIERS!A2` — unchanged rule, verified).
